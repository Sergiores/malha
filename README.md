# Malha

Plataforma de cálculo, verificação normativa e memorial técnico para engenharia
estrutural. Sistema modular, com licenciamento por organização e vencimento
controlado pelo superadmin.

## Rodando localmente

```bash
npm install
```

Copie `.env.example` para `.env` e preencha com os dados do projeto Supabase
(veja `CLAUDE.md` para o detalhamento de cada variável).

```bash
npm run dev
```

## Documentação

`CLAUDE.md` tem a stack, as decisões de arquitetura, os padrões do projeto e o
estado das fases. Leia antes de mexer no código.
